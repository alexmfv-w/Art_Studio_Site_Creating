# Страница «О студии» — контент, компоновка, анимации

Дата: 2026-08-07
Статус: одобрено (диалог с художником), готово как основа для плана реализации

## Контекст и масштаб

Каркас сайта (токены, шапка/футер, попап-меню, главная страница) собран в предыдущем этапе (`2026-08-06-astro-site-frame-plan.md`, выполнен до Task 10). Все 6 маршрутов остальных разделов — страницы-заглушки с текстом «Раздел в разработке». Это первый цикл наполнения одной из них реальным контентом.

Выбрана страница `/o-studii` — по решению художника, как страница, задающая тон остальным (см. диалог: «С какой страницы начнём наполнение контентом?» → «О студии»).

**Явно вне рамок этого документа:**
- Остальные 5 страниц-заглушек (`/vzroslym`, `/detyam`, `/master-klassy`, `/vitrina`, `/kontakty`) — отдельные будущие циклы спека → план → реализация каждая.
- Секция отзывов — компонент верстается, но не выводится на страницу в этом цикле (см. «Отзывы» ниже).
- Реальные фотографии — пока не предоставлены художником, вёрстка использует плейсхолдеры с готовностью принять `src` позже без изменения разметки.

## Источник контента

Сырой текст студии предоставлен художником (объединённый экспорт нескольких постов сообщества ВК, 15 000 подписчиков). Из него по смыслу выделены фрагменты, относящиеся к самой странице «О студии» (история/формат/доверие), остальные (курсы для детей/взрослых, услуги на заказ, контакты) отложены на будущие циклы для соответствующих страниц — см. распределение в диалоге брейнсторминга, не дублируется здесь.

Автоматически вытянуть контент/отзывы напрямую со страницы vk.ru/kistpero не удалось — ВК отдаёт JS-заглушку об устаревшем браузере на нативный (без сессии) запрос; тот же результат на теме с отзывами (`vk.ru/topic-211445225_48862607`). Текст студии получен вставкой от художника напрямую в диалог.

Публичное имя/фамилия художницы решено пока не указывать — текст страницы говорит «мы»/«студия», не от первого лица.

## Контент страницы

### Вступление
- `<h1>` (сериф, `--text-hero` или `--text-h2` — см. «Вёрстка» ниже): «О студии»
- Текст: «Частная студия «Кисть и Перо» — изостудия в Краснодаре» + 1-2 предложения о художественной практике в общих чертах (без вымышленных фактов, которых нет в источнике — не указывать конкретный год основания, если он не был предоставлен)
- `PhotoPlaceholder` рядом (портрет/процесс работы) — фото придёт позже

### Сетка «Почему у нас» (5 карточек)
1. **Опыт** — «Больше 10 лет практики как художник и больше 10 лет преподавания — материал объясняется понятно ученику любого возраста»
2. **Мини-группы** — «3–5 человек в группе — внимание к темпу и особенностям каждого, а не общий поток»
3. **Обратная связь** — «После каждого занятия — видео и фото с пояснениями педагога, видно, как продвигается ученик»
4. **Честная цена** — «Занятия проходят в мастерской на дому у художника — в стоимость не закладывается аренда помещения, только материалы и работа педагога»
5. **Отношение** — «Уважительное и внимательное отношение к ученикам и родителям»

### Формат занятий
- `PhotoPlaceholder` (рабочая комната)
- Текст: «Просторная комната с большим окном, со сплит-системой. Занимаемся и за столами, и на мольбертах — формат зависит от техники.»

### Отзывы
Компонент не создаётся в этом цикле (нет контента). Явно зафиксировано как следующий маленький шаг после того, как художник пришлёт текст отзывов или доступ к теме ВК.

### Завершающий CTA
Кнопка «Записаться» → `/kontakty`, нейтральный регистр кнопки (`--forest` фон, `--radius-sm`).

## Компоненты и вёрстка

Новые файлы:
- `site/src/components/TrustGrid.astro` — принимает пропы `heading: string`, `points: {title: string, text: string}[]`. Рендерит `<h2>` + сетку карточек (`--card` фон, `1px solid var(--line)`, `--radius-md`, `--space-5` padding, акцентная полоса 6px сверху цветом `--forest` — нейтральный регистр, без взрослого/детского окраса, т.к. страница не делит аудиторию). Параметризован (не хардкод, в отличие от `AudienceSplit`), чтобы тот же компонент переиспользовать на `/detyam` с другим набором пунктов в будущем цикле.
- `site/src/components/PhotoPlaceholder.astro` — принимает `alt: string`, необязательный `src?: string`. Без `src` — мягкий брендовый градиентный блок (в духе `Hero`, но приглушённее: тона `--adult-bg`/`--paper`) фиксированных пропорций (`aspect-ratio: 4 / 3`), скруглённый `--radius-md`. С `src` — обычный `<img>` с теми же размерными классами, разметка страницы не меняется при подстановке реального фото.

Изменяемые файлы:
- `site/src/pages/o-studii.astro` — заменяет текущую заглушку. Структура: вступление (2 колонки ≥768px, 1 колонка <768px, как `AudienceSplit`) → `<TrustGrid>` → секция формата (зеркальная раскладка: фото слева на широком экране) → CTA-кнопка.

Типографика по правилу из `2026-08-06-design-system-tokens.md`: `<h1>` и заголовок секции карточек — `--font-display` (сериф), заголовки карточек (`<h4>` внутри `TrustGrid`) и весь остальной текст — `--font-body` (гротеск).

## Анимации

**Scroll-reveal** — чистый CSS, без JS (см. проверку через `modern-web-guidance:scroll-entry-exit-effects`):
```css
@media (prefers-reduced-motion: no-preference) {
  @supports ((animation-timeline: view()) and (animation-range: entry)) {
    @keyframes reveal {
      from { opacity: 0; translate: 0 16px; }
    }
    .reveal {
      animation: reveal auto linear;
      animation-timeline: view();
      animation-range: entry 0% entry 40%;
    }
  }
}
```
Класс `.reveal` — на вступительном блоке, каждой карточке `TrustGrid`, секции формата. Без стаггера (задержек между карточками) — сетка и так попадает в кадр почти одновременно, дополнительная хореография была бы шумом при заявленной цели «минимальные» анимации.

Firefox (нет нативной поддержки `animation-timeline` на момент написания) — прогрессивное улучшение: контент показывается сразу без анимации, полифилл сознательно не используется (эффект декоративный, `scroll-timeline-polyfill` не рекомендован гайдом как неполный).

**Hover/focus:**
- Карточки `TrustGrid`: `transform: translateY(-2px)` (только под `prefers-reduced-motion: no-preference`) + акцентная полоса становится ярче, переход 150ms ease-out.
- `PhotoPlaceholder`: лёгкое затемнение градиента на hover (`filter: brightness(0.95)`).
- CTA-кнопка: `filter: brightness(0.92)` + `translateY(-1px)` на hover (сдвиг — только вне reduced-motion), фокус — существующее глобальное правило `:focus-visible` из `global.css`, не переопределяется.

Все анимируемые свойства — `opacity`/`transform`/`translate`/`filter` (компоновочный поток не трогается, свойства обрабатываются compositor thread'ом браузера).

## Самопроверка

- **Плейсхолдеры:** есть один осознанный незаполненный факт — точный год основания студии/имя художницы не указаны, т.к. отсутствуют в предоставленном источнике; текст написан так, чтобы не требовать этих фактов (безличное «мы»). Это не «TODO», а сознательное решение по итогам диалога.
- **Согласованность:** цвета/шрифты/отступы совпадают с `2026-08-06-design-system-tokens.md`, компоновка (2 колонки → 1 на 768px) — с уже реализованным паттерном `AudienceSplit.astro`. Анимационный подход подтверждён официальным гайдом `modern-web-guidance` (`scroll-entry-exit-effects`), а не изобретён самостоятельно.
- **Масштаб:** документ покрывает ровно одну страницу (`/o-studii`) и два новых переиспользуемых компонента, нужных именно для неё. Секция отзывов и остальные 5 страниц явно вынесены за рамки.
