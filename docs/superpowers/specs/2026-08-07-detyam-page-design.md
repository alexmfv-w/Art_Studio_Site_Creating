# Страница «Детям» — контент, компоновка, переиспользование TrustGrid

Дата: 2026-08-07
Статус: решено самостоятельно (автономная работа, пользователь недоступен для диалога) — решения задокументированы с обоснованием для последующей проверки

## Контекст и масштаб

Второй цикл наполнения контентом после `/o-studii` (см. `2026-08-07-o-studii-page-design.md`). Пользователь передал полную автономию на продолжение работы над сайтом и не участвует в диалоге по этой странице — в отличие от `/o-studii`, здесь нет интерактивного брейнсторминга с вопросами по одному; вместо этого решения приняты на основе уже собранного контента (сырой текст ВК, разобранный по страницам в диалоге о `/o-studii`) и уже одобренной дизайн-системы. Каждое нетривиальное решение ниже явно помечено и обосновано, чтобы пользователь мог быстро проверить и поправить при возвращении.

**Явно вне рамок:** остальные 4 страницы-заглушки, реальные фото (те же плейсхолдеры из `PhotoPlaceholder`, что и на `/o-studii`, фото пока не предоставлены).

## Источник контента

Из сырого текста ВК (тот же источник, что и для `/o-studii`), часть, ранее отнесённая к детскому направлению:
- Керамика (8+)
- Лепка и пластилинография — «особенно полезны детям с задержкой развития речи» (дословно из источника — не редактирую эту заявку художника, просто переношу её текст)
- Каллиграфия брашпеном/ручка-кисть (8+)
- Каллиграфия острым пером (12+)
- Скетчинг и леттеринг — для подростков
- Мини-группы до 4 человек, без наценки за аренду помещения, видео/фото после каждого занятия — те же универсальные пункты доверия, что уже использованы на `/o-studii`; часть родителей попадёт на `/detyam` напрямую из поиска/рекламы, не проходя через `/o-studii`, поэтому короткое повторение ключевых пунктов здесь оправдано, не является бессмысленным дублированием.

Возрастных ограничений для лепки/пластилинографии в источнике не было — бейдж возраста для неё не проставляется (не выдумываю диапазон).

## Решение 1: TrustGrid получает два новых опциональных пропа вместо нового компонента

На финальном ревью `/o-studii` уже было отмечено ограничение: `TrustGrid` и `PhotoPlaceholder` зашивают нейтральный/взрослый регистр цвета (`--forest`, `--adult-bg`) и не параметризуемы снаружи из-за Astro-скоупинга стилей. Ревьюер предложил решение вперёд на будущее — именно этот момент настал.

Вместо создания отдельного компонента «каталог курсов» (что дало бы почти полное дублирование CSS карточки — та же проблема дублирования, которую ревьюер уже поймал на `.btn`), `TrustGrid` расширяется двумя опциональными пропами:
- `accent?: string` — CSS-значение цвета акцентной полосы/рамки при hover, по умолчанию `'var(--forest)'` (сохраняет текущее поведение `/o-studii` без изменений). Применяется через кастомное CSS-свойство `--accent`, выставленное инлайн-стилем на корневой `<section>`, — кастомные свойства наследуются по DOM независимо от скоуп-атрибутов Astro, поэтому это работает.
- Каждый `point` в массиве может нести необязательное поле `badge?: string` — короткая метка (например, «8+», «12+»), отрисовывается в уже задокументированном визуальном стиле бейджа «Доступ» из дизайн-системы (`border: 1px solid var(--ink-soft)`, прозрачный фон, `--font-label`) — переиспользуется существующий паттерн бейджа, а не изобретается новый.

На `/o-studii` `TrustGrid` используется без изменений (без `accent`, без `badge` — оба пропа опциональны, обратная совместимость сохраняется автоматически).

## Решение 2: одна и та же дизайн-система, кастомная тема — не отдельный бренд

Секции страницы используют кид-регистр из уже одобренных токенов (`--kid`, `--kid-bg`, `--radius-pill`) — тот же паттерн, что уже применён в `AudienceSplit.pane.kid`. Кнопка CTA — «детский» регистр кнопки: `background: var(--kid)`, `color: var(--ink)`, `border-radius: var(--radius-pill)`, `font-weight: 800` — скопировано дословно с уже отгруженного `AudienceSplit.astro` (`.pane.kid .btn`), а не с чуть отличающейся формулировки в документе токенов (`color: #FFF7E8`) — приоритет отдан уже смёрженному прецеденту в коде, а не потенциально устаревшей спеке.

## Контент страницы

### Вступление
- Фон секции — `--kid-bg`, как в `AudienceSplit.pane.kid`
- `<h1>` «Детям»
- Текст: «Раскрываем творческие способности ребёнка, развиваем мелкую моторику, усидчивость, воображение. Прививаем любовь к искусству.» (дословно из источника)
- `PhotoPlaceholder alt="Ребёнок на занятии в студии"` рядом (двухколоночная раскладка ≥768px, как на `/o-studii`)

### TrustGrid «Чем занимаемся» (4 карточки, accent=`var(--kid)`)
1. **Керамика** (badge «8+») — «Лепка из глины, обжиг готовых работ»
2. **Лепка и пластилинография** (без бейджа возраста — не указан в источнике) — «Особенно полезны детям с задержкой развития речи»
3. **Каллиграфия брашпеном** (badge «8+») — «Ручка-кисть — понятный формат для первого знакомства с каллиграфией»
4. **Скетчинг и леттеринг** (без бейджа — «для подростков» не даёт точного числа) — «Для подростков — рисование и надписи в популярном сегодня стиле»

Отдельно решено не включать «Каллиграфию острым пером (12+)» пятым пунктом в эту сетку — четыре карточки уже дают ровную сетку `repeat(auto-fit, minmax(220px,1fr))` без разреженного последнего ряда на большинстве брейкпоинтов; острое перо при этом не теряется — про него можно будет упомянуть в будущем при детальной проработке страницы (эта страница — обзорная, не исчерпывающий каталог).

### TrustGrid «Почему у нас» (4 карточки, accent=`var(--kid)`, без бейджей)
Те же формулировки, что и на `/o-studii`, кроме последнего пункта (там был общий «Отношение», здесь заменён на более конкретный для родителя):
1. **Опыт** — «Больше 10 лет практики как художник и больше 10 лет преподавания»
2. **Мини-группы** — «До 4 человек в группе — учитываем возраст и темп каждого ребёнка»
3. **Обратная связь** — «После каждого занятия — видео и фото с занятия, вы видите прогресс ребёнка»
4. **Честная цена** — «В стоимость не закладывается аренда помещения — только материалы и работа педагога»

### CTA
Кнопка «Записаться» → `/kontakty`, кид-регистр (см. «Решение 2»).

## Анимации

Тот же `.reveal` класс из `site/src/styles/animations.css` (уже существует, ничего нового не создаётся) — на вступлении и обеих секциях `TrustGrid` (сами карточки уже несут `.reveal` внутри компонента).

## Самопроверка

- **Плейсхолдеры:** нет — контент и обоснования каждого решения расписаны выше, ничего не оставлено как «уточнить позже» в рамках заявленного объёма. Единственный сознательно неуказанный факт — возраст для лепки/пластилинографии (нет в источнике).
- **Согласованность:** цвета/радиусы — кид-регистр из уже одобренных токенов, кнопка скопирована с уже смёрженного `AudienceSplit.astro`. Расширение `TrustGrid` обратно совместимо (оба новых пропа опциональны), не ломает `/o-studii`.
- **Масштаб:** документ покрывает ровно одну страницу (`/detyam`) и одно точечное расширение существующего компонента — не создаёт новых компонентов, не трогает остальные 4 страницы.
