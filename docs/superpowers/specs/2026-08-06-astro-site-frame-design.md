Дата: 2026-08-06
Статус: одобрено художником, готово для плана реализации

## Контекст и масштаб

Третий этап после выбора визуального направления (`2026-08-06-site-visual-direction-design.md`) и дизайн-системы (`2026-08-06-design-system-tokens.md`). Собирает их в реальный код: общую оболочку сайта на Astro и полностью главную страницу.

**В рамках этого этапа:**
- Инициализация Astro-проекта
- Общая оболочка: шапка с адаптивным меню, футер, базовые стили на токенах
- Главная страница целиком (герой + блок «Взрослым/Детям»), по одобренному макету направления A
- Маршруты-заглушки для остальных разделов схемы сайта (без вёрстки контента)

**Явно вне рамок:** наполнение страниц-заглушек, каталог курсов, личный кабинет, формы записи, интеграции (VK/платежи и т.п.) — отдельные последующие этапы.

## Технические решения

**Стек:** Astro, обычный CSS с custom properties (без Tailwind) — решено на этапе дизайн-системы.

**Мобильное меню — нативный Popover API + Invoker Commands**, без собственного JS-обработчика клика:
```html
<button command="toggle-popover" commandfor="mobile-nav" aria-label="Меню">☰</button>
<nav id="mobile-nav" popover>
  <!-- ссылки навигации -->
</nav>
```
Браузер сам управляет `aria-expanded`, фокусом и light-dismiss. Baseline-статус — «Newly available» (с 2025-12-12), поэтому **обязателен** фидбек-полифилл:
- Фича-детект `'commandForElement' in HTMLButtonElement.prototype` → при отсутствии динамически импортировать `invokers-polyfill`.
- Фича-детект `'popover' in HTMLElement.prototype` → при отсутствии динамически импортировать `@oddbird/popover-polyfill`.
- Полифилл грузится только при реальном отсутствии поддержки — не тянем лишний код в современных браузерах.

**Блок «Взрослым/Детям» — CSS Grid**, две колонки на широких экранах, одна на узких:
```css
.audience-split { display: grid; grid-template-columns: 1fr 1fr; }
@media (max-width: 768px) {
  .audience-split { grid-template-columns: 1fr; }
}
```
Медиа-запрос (не container query) — это композиция уровня страницы, а не изолированного компонента.

**Доступность каркаса:**
- Landmarks: `<header>`, `<nav aria-label="Основная">`, `<main>`, `<footer>`.
- Skip-link перед шапкой, ведущий на `<main id="content" tabindex="-1">`.
- `:focus-visible` стилизован на токенах (`--adult` как цвет outline), без снятия дефолтного фокуса без замены.
- Контраст текста/фона на токенах — `--ink` на `--paper` и `--ink-soft` на `--paper`/`--card` проверяются на соответствие 4.5:1 при вёрстке (см. таблицу токенов в дизайн-системе).

## Содержимое главной страницы

Точный текст и цвета — из одобренного макета направления A (v2, с явным разделением):
- Заголовок героя: «Учим видеть руками»
- Подзаголовок: «Живопись, каллиграфия и керамика в Краснодаре — очно в мастерской и на видеокурсах дома.»
- Панель «Взрослым»: фон `--adult-bg`, акцент `--adult`, текст «Живопись, каллиграфия острым пером, скетчинг, керамика — индивидуально и в мини-группах.»
- Панель «Детям»: фон `--kid-bg`, акцент `--kid`, текст «Лепка, пластилинография, брашпен 8+, керамика — с учётом возраста.»

## Самопроверка

- **Плейсхолдеры:** нет — структура файлов, тексты и технические решения зафиксированы конкретно.
- **Согласованность:** токены и текст совпадают с уже одобренными документами направления и дизайн-системы; маршруты совпадают со схемой сайта из первого этапа проекта.
- **Масштаб:** документ описывает только оболочку + главную; остальные страницы — заглушки без вёрстки, что осознанно оставлено на будущие этапы.
