# Дизайн-система «Кисть и Перо» — токены и базовые компоненты

Дата: 2026-08-06
Статус: одобрено художником вживую (визуальный компаньон), готово как основа для каркаса сайта на Astro (следующий, отдельный этап)

## Контекст и масштаб

Развивает выбранное и одобренное визуальное направление A «Мастерская» (см. `2026-08-06-site-visual-direction-design.md`), где были зафиксированы только цвета и типографика героя и блока «Взрослым/Детям». Здесь это расширяется до полноценного набора токенов и базовых компонентов, достаточного для вёрстки остальных страниц сайта.

**Явно вне рамок этого документа:** сборка каркаса/сетки сайта на Astro (header, footer, контейнеры, брейкпоинты), дизайн конкретных страниц кроме уже одобренных фрагментов героя. Это отдельный следующий этап.

**Решено заранее, не пересматривается здесь:**
- Тёмная тема не нужна — один зафиксированный набор цветов без `prefers-color-scheme`.
- Токены выражаются обычным CSS через custom properties (`--*`), без Tailwind — нативно для Astro, не тянет зависимость.

## Цветовые токены

```css
--forest:      #2C3323;  /* якорный бренд-цвет: шапка, футер, герой, нейтральные кнопки */
--forest-mid:  #3A4530;  /* hover-состояние для forest */
--paper:       #ECEEDF;  /* фон страницы */
--card:        #FAFAF1;  /* фон карточек — чуть светлее paper, различимо без явной границы */
--ink:         #262B1F;  /* основной текст */
--ink-soft:    #5B6350;  /* второстепенный текст, подписи, лейблы */
--line:        #D8DBC7;  /* границы, разделители */

--adult:       #3E4A2E;  /* акцент взрослого контура: кнопки, полосы, бейджи */
--adult-bg:    #C7CBA6;  /* фон взрослых панелей/блоков */
--kid:         #D98A2E;  /* акцент детского контура */
--kid-bg:      #F3E3AE;  /* фон детских панелей/блоков */
```

## Типографические токены

```css
--font-display: Charter, "Bitstream Charter", "Sitka Text", Cambria, serif;
--font-body:    ui-sans-serif, -apple-system, "Segoe UI", Roboto, sans-serif;
--font-label:   ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

Правило распространения: **серифом (`--font-display`) — только hero-заголовок (H1) и крупные заголовки секций (H2)**. Всё остальное — заголовки карточек (H3/H4), тело текста, кнопки, формы, лейблы — гротеском (`--font-body`). Так серифная часть остаётся акцентом бренда, а не тормозит чтение на насыщенных контентом сетках (каталог курсов, карточки направлений).

```css
--text-hero:  clamp(28px, 5vw, 40px);  /* сериф, H1 */
--text-h2:    28px;                     /* сериф */
--text-h3:    20px;  font-weight: 600;  /* гротеск */
--text-h4:    16px;  font-weight: 600;  /* гротеск */
--text-body:  16px;
--text-small: 14px;
--text-label: 12px; text-transform: uppercase; letter-spacing: .06em;  /* моно, эйбрау и метки */
```

## Отступы и радиусы

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
--space-7: 48px;
--space-8: 64px;

--radius-sm:   3px;    /* «взрослые» кнопки — чёткий, точный угол */
--radius-md:   6px;    /* карточки */
--radius-pill: 999px;  /* бейджи, «детские» кнопки — скруглённые, дружелюбные */
```

## Компоненты

### Кнопки — три регистра
- **Нейтральная** (`background: var(--forest)`, `color: #F3F1E4`, `border-radius: var(--radius-sm)`) — для общих CTA вне контура: витрина, контакты, B2B-заявки.
- **Взрослая** (`background: var(--adult)`, `color: #F3F1DE`, `border-radius: var(--radius-sm)`) — для действий внутри контура «Взрослым».
- **Детская** (`background: var(--kid)`, `color: var(--ink)`, `border-radius: var(--radius-pill)`, `font-weight: 800`) — для действий внутри контура «Детям»; более крупный радиус и жирнее текст осознанно отличают её по форме, не только по цвету.

### Карточки
`background: var(--card)`, `border: 1px solid var(--line)`, `border-radius: var(--radius-md)`, `padding: var(--space-5)`. Заголовок — `--text-h4` гротеском, описание — `--text-small` цветом `--ink-soft`.

### Бейджи — два разных вида, различаются формой/заливкой, а не только цветом
- **Аудитория** (взрослым/детям/оба) — заливка: `--adult-bg`/`--adult` для взрослых, `--kid-bg`/тёмно-охристый текст для детей, контурный нейтральный для «оба». Радиус `--radius-pill`.
- **Доступ** (бесплатно/платно/по ссылке/заявка без цены) — только контур (`border: 1px solid var(--ink-soft)`, прозрачный фон, текст `--ink-soft`), шрифт `--font-label`. Разделение по форме (заливка vs контур) специально не даёт спутать два измерения меток на одной карточке.

## Как было проверено

Показано и одобрено вживую через визуальный компаньон brainstorming-скилла: цветовые образцы, типографическая шкала на реальном тексте студии, три регистра кнопок, карточки с бейджами аудитории, бейджи доступа отдельно, шкала отступов. Одобрено без правок.

## Самопроверка

- **Плейсхолдеры:** нет — все значения зафиксированы конкретными числами/hex, ничего не оставлено как «подобрать позже» в рамках заявленного объёма.
- **Согласованность:** цвета и шрифты совпадают с ранее одобренным направлением A (`2026-08-06-site-visual-direction-design.md`) — новые токены (ink, ink-soft, card, line, отступы, радиусы) достраивают, а не переопределяют уже одобренные значения.
- **Масштаб:** документ фиксирует токены и базовые компоненты — не включает вёрстку каркаса сайта, это осознанно отдельный следующий этап.
